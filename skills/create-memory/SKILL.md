# 新增记忆

运行 `python3 scripts/create_memory.py`，让机器人客户端根据当前消息创建长期记忆；当前消息存在直接引用时，被引用消息会与当前消息共同参与提取。

- 用户不需要指定记忆类型。客户端自行推断名称、画像、事实和关系，一次请求可以创建任意数量、任意组合的结构化记忆。
- 没有引用时只处理当前消息；有引用时只处理被引用消息和当前消息，不读取两条消息之间的聊天内容。
- 当前消息必须包含具体指令。只有“记住这个”“记住刚才的”但既没有具体内容也没有引用时，请用户重新说明或引用原消息。
- 不要向脚本传记忆内容、类型、会话信息或微信 ID；脚本只转发当前消息 ID 和可选的引用消息 ID。
- 真实创建时不传 `--dry-run`，也不自动重试超时或连接中断的请求。
- 仅在脚本返回 `ok: true` 后告知用户已记住；失败时直接说明错误，不能声称创建成功。

通过本技能成功创建的所有记忆都由客户端强制设为 `confidence=100`。人物或账号无法唯一对应时，不要猜测。

```bash
python3 scripts/create_memory.py
```
